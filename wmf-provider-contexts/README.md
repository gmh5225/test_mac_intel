# Matched provider raw import and unwind context

This separate read-only domain reuses the earlier current-runtime resolver and
Mach-O reader. Both UUID and complete file/slice hashes must equal the static
dispatch and Blocks files whose selected functions were already captured.

Read complete stub, GOT, compact/DWARF unwind, and exception-table sections when
present, the declared chained-fixup and export-trie payloads, and every file page
named by the actual chained starts metadata. Page and segment identities follow
the file's declared segment order. Pointer formats and encoded words remain raw
for subsequent independent decoding; they are not callable runtime addresses.

No previous function disassembly, inventory, or runtime probe is repeated. No
Simulator is booted and no target provider or original application is executed.
No complete Apple provider binary is uploaded. Raw metadata does not qualify
source values, callbacks, exception semantics, access footprints, or lifetimes.
