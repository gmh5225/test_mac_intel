# Static Simulator Block provider functions

This separate domain reads the iOS Simulator 26.5 (23F77) dispatch and Blocks
implementations using Xcode 26.5. Each static file must have the exact UUID
observed in the earlier independent Simulator process. The previous inventory
and runtime probe are not run again.

For four dispatch and four Blocks entry symbols, preserve the exact ARM64 slice,
load-command and symbol metadata, function-start ranges, all selected function
words, and full bounded disassembler output. Include up to two layers of direct
in-library callees, with deferred direct targets and all indirect branches
explicit. SDK declarations are kept separately from implementation evidence.

Thin provider binaries exist only in the runner's temporary directory and are
not uploaded. No original application or recovered code is uploaded, loaded, or
executed. No Simulator is booted and no provider function is executed in this
domain. Complete selected bodies do not establish a complete call closure,
runtime ownership contract, original-provider match, or source permission.
