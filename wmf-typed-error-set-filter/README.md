# Generic typed-error Set.filter compiler evidence

The two public clients preserve an explicit generic Failure: Error in the
predicate and function throws clause. This is a new source contract alongside
the completed untyped-throws NSObject/generic clients. Five Darwin profiles
produce full IR, SIL and assembly, with all commands, exits and actual Make
dependencies retained. The fixed Xcode 26.5 Swift 6.3.2 compiler and SDK settings
must match their recorded hashes. The old version text is reused.

Only authored source is compiled. Outputs remain static artifacts. Result
shapes, generated symbols and any correspondence with original code are
unknown until independent reading. Compiler conventions remain scoped to these
clients; original ABI, value, frame, borrow, lifetime and effect gates remain
independent.
