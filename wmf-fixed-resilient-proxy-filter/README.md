# Fixed proxy predicate on two existing resilient elements

Two new public clients filter Set values with a fixed NSObject isProxy method
predicate. They take no passed predicate parameter. The two open NSObject
subclasses and all five existing authored Swift module inputs are reused by
full hash and byte identity; no old module or client is recompiled.

The original current 188418 C three-argument word-return declaration differs
from the new previous fixed NSObject predicate kernel Swift declaration. Its
79-word original body is not the previous new 85-word body. These clients
provide a new source contract for complete compiler evidence; no symbol,
body match, ABI, ownership, frame, effect or original source result is assumed.

Fifteen serial IR/SIL/assembly commands use the same pinned Xcode 26.5 Swift
6.3.2 compiler and both SDK settings hashes. Version text is reused. Only
authored source, immutable authored modules and known-toolchain metadata are
uploaded. No original WMF or generated code is executed or linked.
