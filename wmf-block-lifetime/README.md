This is a new authored runtime domain, separate from the completed inventory and all static provider readers. Verify the exact current runtime26.5/23F77, explicit SDK26.5 compiler sysroot, and all four pinned provider UUID plus whole-file and ARM64 slice hashes. A new executable verifies the actual loaded provider UUIDs before any case and runs six authored cases: typed Block_copy and dispatch_source_set_event_handler with three valid compiler-constructed C++ captures.

Source blocks live on a separately allocated pthread stack. After that thread exits and all its capture objects are destroyed, its owned stack is changed to PROT_NONE. The copied callback runs and the last copied capture is disposed while that mapping is still inaccessible. Atomics, semaphores and a complete finite capture event log establish the observed order. Payload types occupy8/32/80bytes; these are authored C++ capture sizes, not an inferred original block extent. Compiler IR, assembly, native binary, complete dependency hashes, runtime stdout/stderr and command receipts are retained. Only the new executable is run; original WMF, generated C, and NeverD code are never executed. Only the one newly created Simulator is shut down/deleted.

The six finite authored observations cannot grant original capture validity, exact memory footprint, borrow/noescape, ownership, lifetime, effects, ABI or source admission. No product R files, SDK behavior, default permissions, original IR/Options/hints or formal method counts change. Provider files are not uploaded. No successful previous workflow or probe is restarted.
