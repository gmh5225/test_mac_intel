# Distinct fixed predicates using the five existing resilient modules

The first client source is unchanged. Only the second client predicate adds
logical negation to isProxy. This creates a genuinely different whole-module
compiler input; it does not rerun the completed identical-predicate job.
Compiler function sharing, signatures, bodies and any original correspondence
remain unknown until the full new outputs are independently read.

All five prior authored module inputs and the elements source remain byte/hash
identical. No old module or client is recompiled. Fifteen serial IR/SIL/assembly
commands use the same compiler and SDK settings hashes with reused version
text. No original WMF input or original/authored generated code is executed.
No old ABI, Origin, names, role, effects, weak linkage, source publication or
source-unit permission is changed by this authored source experiment.
