# Additional native role contracts

These are authored typed source models for comparing exact original native
classifier slices and bounded real-process observations. They are not wired
into the reconstructed engines and do not restore erased producer type names.
Windows has rg/ug/ugrep spellings and case-sensitive `.exe` aliases; its actual
argv basename accepts both slash characters. macOS additionally has bfs and
does not use the Linux apply-seccomp role. The Linux implementation remains in
`bun-runtime/role_contract.rs` and has its own independent evidence.
